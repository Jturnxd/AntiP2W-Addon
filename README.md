# AntiP2W Tools

## About

AntiP2W Tools is a rolling release addon for Meteor Client that provides utilities against pay to win servers.

This README is still WIP, it will be completed later.

## Dependencies

- Minecraft (1.21.4)
- Fabric API (any)
- Meteor Client (0.6.0-SNAPSHOT)
- ViaFabricPlus (4.0.1)
